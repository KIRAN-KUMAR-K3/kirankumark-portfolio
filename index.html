Situation

  • Built Linux automation scripts to streamline enrollment

Results

  • 500+ devices now managed through Intune under a zero-trust compliance baseline
  • 180+ DESE department devices migrated to Entra ID and Intune

Tools: Microsoft Intune, Microsoft Entra ID, Azure AD, Zero Trust (ZTNA), Windows Security, Linux Security

Network and OT

Physical security network hardening

Situation

The institution's IP camera network, deployed campus-wide for physical security, had not been assessed for authentication and network-segmentation risk. Real business risk had to be demonstrated clearly enough to secure stakeholder buy-in, without disrupting live physical-security operations.

What I did

  • Assessed authentication controls across the camera network
  • Ran an authorized proof-of-concept demonstration for stakeholders
  • Delivered a phased remediation plan: credential rotation, access controls and network segmentation
  • Designed a segmented network architecture to isolate physical-security devices

Results

  • Authentication exposure fully remediated and confirmed secured by the infrastructure team
  • Physical-security network isolated on a dedicated segment (DMZ), reducing lateral-movement risk

Skills: Network segmentation, DMZ architecture, IoT / OT security, credential hardening, stakeholder reporting
Security tooling

Shellcraft

Overview

An advanced cybersecurity toolkit designed for security testing, automation, reconnaissance and security research. Built with a modern interface and security-focused workflows to assist analysts and researchers in performing assessments efficiently, with no virtual machine or install required.

Capabilities

  • Sandboxed in-browser Linux shell with a simulated filesystem, process table, tab completion and command history
  • 117-command reference across 13 domains, from search and text processing to permissions, processes, networking and encoding
  • 15 guided challenges on realistic artefacts: web-server logs, rotated archives, CSV and JSON data, in three skill tiers
  • Persistent progress, light and dark themes, responsive down to phones

Analyst workflows

  • Log triage with grep, awk, sed and jq: error counts, top client IPs, hunting across rotated logs
  • Reconnaissance and network analysis: ping, dig, traceroute, curl, ss, nc and tcpdump
  • Process and service hunting: ps, pgrep, journalctl, systemctl and crontab
  • Integrity and encoding checks: sha256sum, base64, xxd and strings

Technologies: HTML, CSS, JavaScript, security automation
